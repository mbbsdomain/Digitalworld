Discipline-wise Man-hours (MHs)

Column 1 is filled by the discipline lead; Column 2 is the Proposal Co-ordinator's assumed value. Estimated MHs = MIN(Col 1, Col 2); however, if either column is blank/0, Estimated MHs takes the value of whichever column is greater than 0. Man-Month (MM) = Estimated MHs ÷ K (from Input Sheet).

Manpower Deployment Histogram

Man-Month (MM) for each discipline (from MHs Sheet) is distributed across the project schedule in a parabolic (bell-shaped) build-up/de-mobilisation curve. Each bar is a month; each colour segment is a discipline (hover a segment for its value), and the number above each bar is that month's total headcount.
X-axis: project month (M1, M2, …). Y-axis: number of persons deployed that month, stacked by discipline.
